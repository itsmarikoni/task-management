# 機能要件 - Trello風タスク管理アプリ

[要件定義書](requirements.md) に対応する機能要件・ユースケース詳細ドキュメント。

## 1. 基本機能

| 機能 | 内容 |
|---|---|
| ボード | プロジェクト単位の作業スペース |
| カラム(リスト) | 「未着手」「進行中」「完了」など、カードを分類する列 |
| カード | 個々のタスクを表す単位 |
| ドラッグ&ドロップ | カードをカラム間でマウス操作により移動できる |

## 2. カード(タスク)が持つ情報

- タイトル
- 説明文
- 優先度(例:高・中・低)
- 期限(日付)

## 3. CRUD操作

- カードの作成・編集・削除
- カラムの作成・編集・削除

## 4. ユースケース

### 4.1 ユースケース一覧

| ID | ユースケース名 | 概要 |
|---|---|---|
| UC-01 | カラムを追加する | 新しいカラム(ステータス)をボードに追加する |
| UC-02 | カラム名を変更する | 既存のカラムの名前を変更する |
| UC-03 | カラムを削除する | 不要になったカラムを削除する |
| UC-04 | カードを追加する | 指定したカラムに新しいカードを追加する |
| UC-05 | カードの詳細を編集する | カードのタイトル・説明文・優先度・期限を編集する |
| UC-06 | カードを別カラムへ移動する | ドラッグ&ドロップでカードのステータスを変更する |
| UC-07 | カードの並び順を変更する | 同一カラム内でカードの表示順を入れ替える |
| UC-08 | カードを削除する | 不要になったカードを削除する |
| UC-09 | カードを並び替える | カラム内のカードを優先度順・期限順に一括で並び替える |

### 4.2 基本フロー

**UC-01: カラムを追加する**
- アクター: 利用者
- トリガー: ボード画面で「カラム追加」ボタンをクリックする
- 基本フロー:
  1. 利用者が「カラム追加」ボタンをクリックする
  2. カラム名の入力欄がその場に表示される(インライン入力)
  3. 利用者がカラム名を入力し、保存する
  4. ボードに新しいカラムが追加される

**UC-02: カラム名を変更する**
- アクター: 利用者
- トリガー: カラムヘッダーの「…」メニューから「名前を変更」を選択する
- 基本フロー:
  1. 利用者がカラムヘッダーの「…」メニューをクリックする
  2. メニューから「名前を変更」を選択する
  3. カラム名がその場でテキスト編集可能になる(インライン編集)
  4. 利用者が名前を編集し、確定する
  5. カラム名が更新される

**UC-03: カラムを削除する**
- アクター: 利用者
- トリガー: カラムヘッダーの「…」メニューから「カラムを削除」を選択する
- 基本フロー:
  1. 利用者がカラムヘッダーの「…」メニューをクリックする
  2. メニューから「カラムを削除」を選択する
  3. 削除確認ダイアログが表示される
  4. 利用者が「削除する」を選択する
  5. カラムとその中の全カードが削除される

**UC-04: カードを追加する**
- アクター: 利用者
- トリガー: カラム内の「カード追加」ボタンをクリックする
- 基本フロー:
  1. 利用者が対象カラムの「カード追加」ボタンをクリックする
  2. カード詳細(編集)画面がモーダルで表示される
  3. 利用者がタイトル等を入力し、保存する
  4. 対象カラムの末尾に新しいカードが追加される

**UC-05: カードの詳細を編集する**
- アクター: 利用者
- トリガー: ボード画面上のカードをクリックする
- 基本フロー:
  1. 利用者がカードをクリックする
  2. カード詳細(編集)画面がモーダルで表示される
  3. 利用者が内容を編集し、保存する
  4. 変更内容がカードに反映される

**UC-06: カードを別カラムへ移動する**
- アクター: 利用者
- トリガー: カードをドラッグして別カラムにドロップする
- 基本フロー:
  1. 利用者がカードをドラッグする
  2. 移動先のカラムにドロップする
  3. カードの所属カラムが更新される

**UC-07: カードの並び順を変更する**
- アクター: 利用者
- トリガー: 同一カラム内でカードをドラッグする
- 基本フロー:
  1. 利用者がカードをドラッグする
  2. 同一カラム内の別の位置にドロップする
  3. カードの表示順が更新される

**UC-08: カードを削除する**
- アクター: 利用者
- トリガー: カード詳細画面で「削除」ボタンをクリックする
- 基本フロー:
  1. 利用者が「削除」ボタンをクリックする
  2. 削除確認ダイアログが表示される
  3. 利用者が「削除する」を選択する
  4. カードが削除される

**UC-09: カードを並び替える**
- アクター: 利用者
- トリガー: カラムヘッダーの「…」メニューから「優先度順に並び替え」または「期限順に並び替え」を選択する
- 基本フロー:
  1. 利用者がカラムヘッダーの「…」メニューをクリックする
  2. メニューから「優先度順に並び替え」または「期限順に並び替え」を選択する
  3. 選択した基準でカラム内のカードが一括で並び替えられる(優先度順は高→中→低、期限順は期限が早い順。期限未設定のカードは最後)
- 補足: この並び替えを行った後も、ドラッグ&ドロップによる自由な並び替え(UC-07)は引き続き可能。
