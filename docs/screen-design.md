# 画面設計 - Trello風タスク管理アプリ

[要件定義書](requirements.md) に対応する画面設計詳細ドキュメント。

## 1. 画面一覧

| 画面名 | 概要 |
|---|---|
| ボード画面 | アプリのメイン画面。カラムとカードの一覧・操作を行う。 |
| カード編集フォーム | カードのタイトル・説明文・優先度・期限を編集する。ボード画面内でカードの位置にインライン表示される(モーダルではない)。 |
| 削除確認ダイアログ | カード削除前に、誤操作防止のためブラウザ標準の確認ダイアログ(`window.confirm`)を表示する。 |

カラムの追加・名前変更・削除は、いずれもボード画面内でインラインに操作する(モーダルではない)。カラム名はヘッダーをクリックしてインライン編集、削除はヘッダーの「✕」ボタン(ブラウザ標準の確認ダイアログを表示)、追加はボード末尾の「+ カラム追加」ボタンから行う。詳細は[機能要件](functional-requirements.md)のUC-01〜03を参照。

## 2. 画面遷移図

```mermaid
flowchart LR
    A[ボード画面] -->|カードをクリック| B[カード編集フォーム(インライン)]
    B -->|保存| A
    B -->|キャンセル| A
    A -->|「カード追加」ボタン| B
    A -->|カード上の「✕」ボタン| C[削除確認ダイアログ(window.confirm)]
    C -->|OK| A
    C -->|キャンセル| A
    A -->|カードをドラッグ&ドロップ| A
    A -->|カラムヘッダーの「優先度」/「期限」ボタン| A
```

## 3. 各画面の構成要素

**ボード画面**
- 複数のカラムが横並びで表示される。
- 各カラムの中にカードが縦に並ぶ。
- 各カラムの上部にカラム名・カード件数・「優先度」ボタン・「期限」ボタンを表示する。
- カラム名の横にそのカラムに含まれるカードの合計件数を表示する。
- 「優先度」ボタンをクリックすると、カラム内のカードが優先度順(高→中→低)に一括で並び替えられる。
- 「期限」ボタンをクリックすると、カラム内のカードが期限が早い順に一括で並び替えられる(期限未設定のカードは最後)。
- 並び替え後もドラッグ&ドロップによる自由な並び替えは可能。
- 各カラムの下部に「カード追加」ボタンを表示する。
- カードには最低限、タイトルと優先度が一覧表示される。
- カラムの追加・名前変更・削除UIは現時点では存在しない(カラムは「未着手」「進行中」「完了」の3つで固定)。

**カード編集フォーム(インライン)**
- タイトル(テキスト入力)
- 説明文(複数行テキスト入力)
- 優先度(選択式:高・中・低)
- 期限(日付選択)
- 「保存」「キャンセル」の操作ボタンを配置する。
- ボード画面の中で、対象カードの表示位置にその場で展開される(モーダル/ポップアップではない)。
- 削除は本フォーム内ではなく、カード自体に表示される「✕」ボタンから行う。

**削除確認ダイアログ**
- カード上の「✕」ボタンをクリックすると、ブラウザ標準の`window.confirm`ダイアログで確認メッセージを表示する。
- カスタムスタイルのモーダルではない。

## 4. ワイヤーフレーム

**ボード画面**

```
+--------------------------------------------------------------+
| タスク管理ボード                                              |
+--------------------------------------------------------------+
| 未着手 (2) [優先度][期限] | 進行中 (2) [優先度][期限] | 完了 (1) [優先度][期限] |
|---------------------------|---------------------------|---------------------------|
| [カード1      ]  ✕      | [カード3      ]  ✕      | [カード5      ]  ✕      |
| 優先度:高                 | 優先度:中                 | 優先度:低                 |
|---------------------------|---------------------------|---------------------------|
| [カード2      ]  ✕      | [カード4      ]  ✕      |                           |
| 優先度:中                 | 優先度:高                 |                           |
|---------------------------|---------------------------|---------------------------|
| [+ カード追加]            | [+ カード追加]            | [+ カード追加]            |

  (n) はそのカラムのカード件数

```

```
+----------------------------------+
```

## 5. 操作仕様

- カードをドラッグして別のカラムにドロップすると、ステータス(カラム)が変わる。
- カードをクリックすると、その場でインラインの編集フォームに切り替わり、タイトル・説明文・優先度・期限を編集できる。
- カード上の「✕」ボタンをクリックすると、ブラウザ標準の確認ダイアログ(`window.confirm`)を表示したうえで削除する。
- カラムヘッダーの「優先度」「期限」ボタンから、カラム内のカードを優先度順・期限順に一括で並び替えられる。
- カラムの追加・名前変更・削除は現時点では未実装。
